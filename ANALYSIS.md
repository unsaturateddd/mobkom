## Описание функций

### config.py
- `BOT_TOKEN` — токен Telegram бота
- `ADMIN_ID` — ID админа
- `SMS_NUMBER` — номер для отправки SMS (7878)
- `REPLY_NUMBER` — номер для отслеживания ответов (8464)
- `CONFIRM_TEXT` — текст подтверждения оплаты
- `RURU_TEXT` — текст ошибки оплаты
- `SIGNAL_TEXT` — текст сигнала для рассылки
- `WS_HOST/PORT` — настройки WebSocket сервера

### database.py
**Users:**
- `add_user()` — добавление пользователя
- `get_user()` — получение пользователя
- `get_role()` — получение роли
- `set_role()` — установка роли
- `get_all_users()` — список всех пользователей
- `get_all_users_with_signal()` — пользователи с активными сигналами

**Phones:**
- `register_phone()` — регистрация телефона
- `get_phones()` — список телефонов
- `assign_phone()` — привязка телефона к трейдеру
- `update_phone_status()` — обновление статуса

**Trader Settings:**
- `get_trader_settings()` — настройки трейдера
- `update_trader_settings()` — обновление настроек

**Purchases:**
- `add_purchase()` — добавление откупа
- `get_purchases()` — список откупов
- `get_purchase()` — получение откупа
- `toggle_purchase()` — включение/выключение
- `delete_purchase()` — удаление

**QR Tokens:**
- `save_qr_token()` — сохранение токена
- `validate_qr_token()` — проверка и использование токена

**Logs:**
- `log()` — запись лога
- `get_logs()` — получение логов

### bot.py
**Меню:**
- `main_menu()` — главное меню
- `panel_menu()` — панель трейдера
- `admin_panel_menu()` — админ-панель

**Обработчики:**
- `cmd_start()` — /start
- `handle_callback()` — обработка нажатий кнопок
- `handle_message()` — обработка текстовых сообщений

**Функции:**
- `generate_qr_image()` — генерация QR кода
- `time_in_bot()` — время в боте
- `broadcast_signal()` — рассылка сигналов

### websocket_server.py
- `handler()` — обработка подключений
- `handle_8464_response()` — обработка ответов от 8464
- `send_to_phone()` — отправка команды телефону
- `broadcast_sms()` — рассылка SMS со всех телефонов

### signal_handler.py
- `handle_incoming_signal()` — обработка входящего SMS
- `process_confirmed_signal()` — обработка подтверждения
- `execute_auto_buy()` — выполнение авто-откупа
- `wait_for_response()` — ожидание ответа

## Проблемы и улучшения

### 🔴 Критические
1. **Нет авторизации WebSocket** — любой может подключиться
2. **Нет валидации токенов по времени** — токены не истекают
3. **Нет обработки ошибок WebSocket** — падение при разрыве
4. **SQLite для продакшена** — нужно PostgreSQL

### 🟡 Важные
5. **Нет rate limiting** — можно заспамить бота
6. **Нет кеширования** — частые запросы к БД
7. **Нет healthcheck** — нет проверки состояния сервера
8. **Нет метрик** — нет статистики по производительности

### 🟢 Улучшения
9. **Красивые логи** — добавить эмодзи и форматирование
10. **Экспорт данных** — выгрузка в CSV/Excel
11. **Уведомления** — push-уведомления админу
12. **Резервное копирование** — автобекап БД
